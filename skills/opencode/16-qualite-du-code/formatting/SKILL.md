# Formatting

**Catégorie :** 16. Qualité du code — Pack *Web Master AI*

## Objectif
Configurer un formateur de code automatique (prettier ou équivalent) pour un style uniforme.

## Quand déclencher cette skill
- L'utilisateur demande explicitement de travailler sur « formatting »
- La tâche en cours implique configurer un formateur de code automatique (prettier ou équivalent) pour un style uniforme
- Un fichier, un module ou une fonctionnalité du projet touche directement ce sujet
- Une revue de code, un audit ou une nouvelle fonctionnalité en dépend

## Checklist / bonnes pratiques
- Préférer un code simple et lisible à un code 'intelligent' mais obscur
- Nommer clairement variables, fonctions et fichiers selon leur rôle réel
- Éviter la duplication en factorisant ce qui est vraiment réutilisé
- Garder les fonctions courtes et responsables d'une seule chose
- Automatiser lint/format pour éviter les débats de style
- Documenter le 'pourquoi', pas seulement le 'quoi'

## Démarche recommandée
1. Clarifier le besoin exact et le contexte du projet (stack, contraintes, existant)
2. Identifier les options possibles et choisir la plus adaptée au contexte (pas la plus complexe)
3. Mettre en œuvre par petites étapes vérifiables
4. Vérifier le résultat par rapport à la checklist ci-dessus
5. Signaler explicitement les limites, risques ou points restant à valider

## Livrables attendus
- Une solution concrète et fonctionnelle pour « formatting », adaptée au projet en cours
- Une explication claire des choix effectués et de leurs compromis
- La liste des points de vigilance ou suites possibles, le cas échéant
